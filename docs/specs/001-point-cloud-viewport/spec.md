## 1. 问题陈述

技术栈（ADR 006）已确认但未被任何真实代码验证。RoboView 需要一个**端到端可见的第一个切片**：
用户打开应用 → 通过应用内原生文件选择入口打开本地点云文件 → 点云经 GPU 渲染显示在 3D 视口中 →
轨道相机交互。此切片同时验证三件事：分层边界（core 零 GUI 依赖、可脱离 GUI 编译）、
渲染链路（真实数据从文件到 GPU）、跨平台（CI 三平台矩阵在新依赖下成立）。
本功能完成后，RoboView 从"骨架"变成"可以打开自己的数据"的第一步。

## 2. 成功指标（可测试）

| # | 指标 | 判定 |

| M3 | 性能 | 采用**固定测量协议**（见 A11/A12）：release 构建、参考机型记录（型号/OS/分辨率）、计时起点=对话框确认至首帧显示、最慢样本（100 万点 ASCII PLY）；显示阶段以固定自动环绕 5s 采样帧时间（p95），目标 p95 < 16.7ms，无持续掉帧 |

## 3. 用户故事

- **US1**：作为开发者，我启动 RoboView，视口为空；点击"打开点云文件"，选择本地的 PLY/PCD 文件，点云显示在视口中央，我可以拖动环绕、滚轮缩放查看。
- **US2**：作为开发者，我打开第二个文件时，视口中的点云被替换为新的数据；若新文件失败（不支持/损坏），视口保留上一次成功显示的点云并显示错误。
- **US3**：作为开发者，我误选了不支持的文件格式，或文件损坏，应用显示可读的错误提示而不是崩溃。

## 5. 非目标（本功能明确不做）

- 不显示网格、路径、frame、marker、计算图（第二个功能起）。
- 不做坐标系树 / TF 帧传递、拾取（点击选择相机）、尺寸标注 UI。
- 不做拖放打开、命令行参数打开（仅原生对话框一个入口）。
- 不做多文件/批量打开（单文件替换语义，US2）。
- 不做点大小/点样式控制 UI、按属性染色 UI 开关、截图导出、背景色/主题切换。
- 不做 UI 面板停靠（egui_dock）、布局持久化。
- 不支持 LAS/LAZ、PCD 压缩（LZ4）、big-endian 二进制、多帧/序列动画。
- 不渲染强度、法线等附加属性（仅 x/y/z 与可选 RGB）。
- 不使用第三方 loader crate（解析器自研）。
- 不做 2D 视图、数据表面板。

## 6. 约束

- 技术栈固定：`wgpu` + `glam` + `bytemuck`（core）；`eframe` + `egui`（app）（ADR 006）。
- 分层：解析/格式（io）、显示类型（displays/point_cloud）、渲染（render）、相机状态与数学（core）；对话框与输入事件映射在 app。
- 所有新增依赖必须：许可兼容 `MIT OR Apache-2.0`（deny 白名单内）、在提交信息中说明用途（§2.8.1）；core 的依赖不得引入 GUI crate（§2.4.1）。
- MSRV 1.85（CI msrv job 验证）；三平台（CI 矩阵验证）。
- 文件选择入口使用**系统原生对话框**（具体实现方案在 plan.md 中选定，须覆盖三平台并许可兼容）。
- UI 文案英文优先，i18n-ready 结构（§6.5）；错误信息用户可读、不 panic（§2.5）。
- 测量口径：M3/A11 固定协议一旦采用，性能回归以两次同基线数据为准（记录而非口头）。

## 7. 格式支持范围（本期锁定；范围调整须修订本规格并重新批准）

| # | 格式 | 支持子集 | 关键裁定 |
|---|---|---|---|
| F1 | **PLY** | ASCII 与 binary_little_endian；字段至少 `x y z`，可选 `r g b`（uchar 三字节，按文件字段顺序）或 `rgb`（三字节 uchar 方言） | 目标数据域（机器人感知/仿真）最常见的两种导出格式，结构简单可全控；解析细节（stride/边界）见 plan.md 格式矩阵 |
| F2 | **PCD** | Version 0.7；`ascii` 与 `binary_little_endian`；字段 `x y z`，可选 `rgb`（float 打包，位序约定见 plan.md） | 同上；`TYPE/SIZE/COUNT` 组合枚举见 plan.md |
| G1 | 无效点 | 文件中的 `nan`/`inf` 坐标**保留**在数据数组中；渲染时跳过；包围盒计算排除非有限值并按异常情形防御 | 机器人真实数据含无效点是常态，拒载整文件可用性差 |
| G2 | 亮度 | 无颜色文件使用统一默认色（值见 plan.md） | — |
| — | 不支持的输入 | LAS/LAZ、OBJ（网格）、XYZ/CSV/TXT（任意列，歧义多）、机器人运行时录制数据（多帧流式） | 明确拒绝并给出可读错误；扩展单独立项 |

判定口径：扩展名 + 文件头双校验；格式不支持或校验失败时不尝试解析，直接以明确错误拒绝（A8）。
大端二进制：不属于支持子集（PCD 无端序标记，小端解析器遇大端文件可能静默错读——记入已知限制，不做过度防护）。
