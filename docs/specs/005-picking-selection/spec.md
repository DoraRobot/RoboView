## 1. 问题陈述

004 建立"树上选中 → 属性面板"链路，但 3D 视口无命中能力：无法"点内容"选中。本功能补上
**视口拾取与选中高亮**，并让选中成为三区（树/视口/属性）的同一主语；同时打通 002 遗留的
"无选中交互"缺口（`002-display-types spec.md` §5 非目标中"拾取"的解锁即本功能）。

**取代声明**：`002-display-types spec.md` §5 的"不做拾取"非目标由本功能取代（进入已实现）；
`001-point-cloud-viewport spec.md` §5 的"拾取（点击选择相机）"非目标一并解锁——001 与 002 修订行均登记。

## 2. 成功指标（可测试）

| # | 指标 | 判定 |
|---|---|---|
| M1 | 视口命中 | 点击（对应拾取模式）命中显示对象：点云/网格/路径/坐标系线/标记箭头——拾取命中即选中 |
| M2 | 命中精度 | 可判定的精度口径（见 A2）；大对象包围盒误命中率按 A 判据 |
| M3 | 选中高亮 | 选中对象在视口可见的高亮表现（高亮方式见 §6），取消选中即时恢复 |
| M4 | 三区镜像 | 视口选中 ↔ 树行 ↔ 属性面板联动 ≤1 帧（任一来源选中，三处同步） |
| M5 | 聚焦与删除 | F 键聚焦选择集（相机取景到选中对象并集）；Delete 删除选择集（A6 语义沿用 002） |
| M6 | 回归 | 001–004 全量（002/003 语义等价）+ A9 守卫 + 五门禁 |
| M7 | 默认键位 | 与专业 3D 软件一致（键位表 A11）：左键=点选+框选，中键=轨道，Shift+中键=平移，滚轮=缩放（光标锚定），Shift/Ctrl+左键=加选/减选 |

## 3. 用户故事

- **US1**：我点击视口中的网格 → 它被高亮，右面板显示网格属性，树行也选中。
- **US2**：点击点云密集区 → 命中最红/最近点附近对象；空点处点击取消选中。
- **US3**：我按 F → 视角聚焦到选中对象；按 Delete → 删除（保留既有对象的失败语义不变外，本次直接删除本体）。
- **US4**：我点路径线条/坐标系轴/标记箭头 → 均按整对象命中（线类按投影距离阈值）。

## 4. 验收标准（渠道：CI=自动，UT=单测，MAN=手工）

| # | 验收 | 渠道 |
|---|---|---|
| A1 | 点击网格（≥100 面）聚焦处 → 选中并高亮（高亮色 = 004 token）；移出则恢复；marker 文字标签命中（屏幕空间锚框，命中=选中箭头对象）同判 | MAN |
| A2 | 精度判据（固定口径）：mesh/线类按**投影后屏幕距离** ≤ 阈值 δ（δ=视口逻辑高度 × 0.5%，与 A5 相机无关一致，文档化）；点云按投影屏幕半径 r=8px（egui 逻辑点；物理像素 = r × pixels_per_point，文档化）的近邻命中；含"等距双对象时命中最先绘制/最近者"规则 | UT（数学）+MAN |
| A3 | 点云命中：抽 5 个已知点坐标点击（投影后屏幕位置）→ 命中该点（用户数据对象）；点间空隙点击 → 未命中 | UT+MAN |
| A4 | 三区镜像：视口点选 → 树行/属性 ≤1 帧同步；树行点选 → 视口高亮 ≤1 帧 | MAN |
| A5 | 平移/缩放后命中仍正确（相机无关的射线计算）；非有限坐标/退化包围盒不 panic | UT+MAN |
| A6 | F 聚焦选择集（相机取景到选中对象 bounds 并集；无选中 F 无操作）；Delete 删除选择集（`002-display-types spec.md` A6 资源台账判据复用）；两键仅在无文本焦点输入时生效（egui 焦点门控） | MAN |
| A7 | 高速扫动（10 次/秒点选）不崩、不残留高亮 | MAN |
| A8 | 回归：001–004 + 路径守卫（`001-point-cloud-viewport spec.md` A9）+ 五门禁/三平台/msrv | CI+MAN |
| A9 | 框选：左键按下→拖出矩形（位移 ≥4px 进入框选，橡皮筋实时反馈；拖前抬起=点选）→ 抬键结算：与矩形**接触**（投影包围框与矩形相交即算，相机无关）的全部可拾取对象入选；空白框选→清空选择；Esc 清空 | MAN |
| A10 | 多选联动：框选/Shift+左键加选产生**选择集**（app 层对象集，不动 core 模型）；集内全部对象视口均高亮（004 per-object 通道逐对象置位）；**单选**时树/属性维持 004 A3/A4；**多选**时属性面板降级"已选 N 个对象"概要（禁编辑）、树行为合集高亮；Ctrl+左键=减选（含"减到空"） | MAN |
| A11 | 默认键位表（一个视口一套映射，无独占工具模式）：左键点击（<4px）=点选（命中判据 A2）／空白=清空；左键拖=框选（A9）；中键拖=轨道；Shift+中键拖=平移（轨道/平移同"抓取"手感，轨道朝相机第 5 感）；滚轮=缩放（**光标锚定**——缩放前后光标下世界点经 `pointer_world` 复映射漂移 ≤ 视口高 × 0.5%，UT 断言）；Shift+左键=加选；Ctrl+左键=减选；**模拟三键（无中键鼠标，Blender 同款）**：Alt+左键=中键（轨道）、Shift+Alt+左键=Shift+中键（平移）、Alt 按下时点选/框选不触发；Esc=清空；F=聚焦选择集；Delete=删除选择集 | UT+MAN |
| A12 | 选择集生命周期：平移/缩放/轨道后 A9 结果不漂移（命中判据相机无关）；10 次/秒框选高速操作不崩、无残留高亮（每轮结算后集内对象通道状态复位审计） | UT+MAN |

## 5. 非目标（本功能不做）

- 不做对象拖拽变换/旋转 Gizmo（另立项，路线图序号 008）；**不做多选之上的批量批操作**（批量属性编辑/批量移动——多选基元本身属本功能 A10，批量编辑归后续立项）。
- 不做属性面板的编辑扩展（004 已定范围：颜色/文本/长度等；更复杂编辑另立项）。
- 不做可见性/半透明策略改（沿用 002 显隐即跳过绘制）。
- 不做高亮渲染的二次通道之外的效果（发光/描边等视觉增强——007）。
- **不做独占工具模式**（无"选择/环绕"工具切换，一个视口一套默认键位，见 A11）：左键=点选+框选、中键=轨道、Shift+中键=平移、滚轮=缩放（光标锚定）、Shift/Ctrl+左键=加选/减选（未来工具占位另立项）。
- 不做语义色对象（frame 坐标轴）的选中换色高亮：拾取/选中对这些对象仍成立（树/属性联动），视口 tint 豁免——保留 002 锁定的 AXIS_X/Y/Z 语义色。（地面网格为 004 视口辅助层：不入场景树、不可拾取，不在此列。）
- 不做拾取点击后右键"重命名/删除"之外的编辑命令（"重命名/删除"归属 **007 视口右键表**；上下文菜单完整版 007）。
- **范围锁定**：调整命中策略/阈值/高亮风格须修订本规格并重新批准（008 须另立 spec 并经批准）。

## 6. 约束

- **拾取实现路线（定案）**：CPU 侧数学射线 + 各类型命中测试（mesh：BVH/逐三角形；线：胶囊距离；
  点云：像素半径近邻 + 空间索引）；GPU 离线拾取通道与深度采样拾取不采用（带宽/同步成本、受深度限制、
  线类不可用）。CPU 路线确定性、可单测，并与 `001-point-cloud-viewport spec.md` §7 G1（非有限坐标判据）协调。
- **高亮方式（定案，复用 004 通道）**：绘制时置位 `004-ui-blueprint spec.md` §6"视口高亮机制"建立的
  per-object 外观 uniform（外观色覆盖 + 选中标识——三管线 bind group/WGSL/上传路径同源扩展）；本功能只加
  "命中 → 写选中标识"逻辑，**不新增渲染通道**。（原"零资源重传"表述已证伪：该通道实为 004 内的中等规模
  管线重构；二次通道/发光描边不再考虑。）
- 命中计算在 UI 线程（点击率低）；点云近邻空间索引：命中测试与索引构建放 core 新模块（`render/pick.rs`
  类纯函数，可单测），**索引缓存驻 app 层**（`ViewportState` 内 `HashMap<u64, Arc<…>>`，随 `Scene::remove`
  同生命周期失效重建）——不动 `io`/`display` 数据结构（004 层界）。
- 坐标转换：屏幕↔NDC↔射线——core 数学、可单测：`screen_to_ray` 已随 004 在 `camera_math.rs` 落位
  （004 状态栏坐标同源），本功能在其上叠加对象命中层；`OrbitCamera::eye()/view_axes()` 保持私有，
  经 `view_proj.inverse()` 两点反投影构造射线（glam 0.33 无 unproject，已验证）。
- 语义色与高亮色共用 004 色板（frame 轴等语义色对象豁免 tint，见 §5）；i18n 文案走 key 表（新键 2-3 个）；路径守卫（`001-point-cloud-viewport spec.md` A9）照旧。
