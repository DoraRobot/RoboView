# picking-selection — 规格

状态：Draft（草案）

日期：2026-09-02

相关：ADR 004、ADR 006；`docs/specs/002-display-types/`（显示类型）、`docs/specs/004-ui-blueprint/`（本功能前置：属性面板/树上选中已就位）

> 跨 workspace 引用全限定；裸编号仅本 workspace 有效。

## 1. 问题陈述

004 建立"树上选中 → 属性面板"链路，但 3D 视口无命中能力：无法"点内容"选中。本功能补上
**视口拾取与选中高亮**，并让选中成为三区（树/视口/属性）的同一主语；同时打通 002 遗留的
"无选中交互"缺口（002 spec §5 非目标中"拾取"的解锁即本功能）。

**取代声明**：002-display-types 的"不做拾取"非目标由本功能取代（进入已实现）；002 修订行登记。

## 2. 成功指标（可测试）

| # | 指标 | 判定 |
|---|---|---|
| M1 | 视口命中 | 点击（对应拾取模式）命中显示对象：点云/网格/路径/坐标系线/标记箭头——拾取命中即选中 |
| M2 | 命中精度 | 可判定的精度口径（见 A2）；大对象包围盒误命中率按 A 判据 |
| M3 | 选中高亮 | 选中对象在视口可见的高亮表现（高亮方式见 §6），取消选中即时恢复 |
| M4 | 三区镜像 | 视口选中 ↔ 树行 ↔ 属性面板联动 ≤1 帧（任一来源选中，三处同步） |
| M5 | 聚焦与删除 | F 键聚焦选中（相机取景到对象并集）；Delete 删除选中（A6 语义沿用 002） |
| M6 | 回归 | 001–004 全量（002/003 语义等价）+ A9 守卫 + 五门禁 |

## 3. 用户故事

- **US1**：我点击视口中的网格 → 它被高亮，右面板显示网格属性，树行也选中。
- **US2**：点击点云密集区 → 命中最红/最近点附近对象；空点处点击取消选中。
- **US3**：我按 F → 视角聚焦到选中对象；按 Delete → 删除（保留既有对象的失败语义不变外，本次直接删除本体）。
- **US4**：我点路径线条/坐标系轴/标记箭头 → 均按整对象命中（线类按投影距离阈值）。

## 4. 验收标准（渠道：CI=自动，UT=单测，MAN=手工）

| # | 验收 | 渠道 |
|---|---|---|
| A1 | 点击网格（≥100 面）聚焦处 → 选中并高亮（高亮色 = 004 token）；移出则恢复 | MAN |
| A2 | 精度判据（固定口径）：mesh/线类按最近表面距离 ≤ 阈值 δ（δ=视口高度 × 0.5%，文档化）；点云按投影像素半径 r=8px 的近邻命中；含"等距双对象时命中最先绘制/最近者"规则 | UT（数学）+MAN |
| A3 | 点云命中：抽 5 个已知点坐标点击（投影后屏幕位置）→ 命中该点（用户数据对象）；点间空隙点击 → 未命中 | UT+MAN |
| A4 | 三区镜像：视口点选 → 树行/属性 ≤1 帧同步；树行点选 → 视口高亮 ≤1 帧 | MAN |
| A5 | 平移/缩放后命中仍正确（相机无关的射线计算）；非有限坐标/退化包围盒不 panic | UT+MAN |
| A6 | F 聚焦（相机取景到该对象 bounds；无选中 F 无操作）；Delete 删除选中（002 的 A6 判据复用） | MAN |
| A7 | 高速扫动（10 次/秒点选）不崩、不残留高亮 | MAN |
| A8 | 回归：001–004 + A9 守卫 + 五门禁/三平台/msrv | CI+MAN |

## 5. 非目标（本功能不做）

- 不做对象拖拽变换/旋转 Gizmo（另立项）；不做多选（一次一个）。
- 不做属性面板的编辑扩展（004 已定范围：颜色/文本/长度等；更复杂编辑另立项）。
- 不做可见性/半透明策略改（沿用 002 显隐即跳过绘制）。
- 不做高亮渲染的二次通道之外的效果（发光/描边等视觉增强——007）。
- 不做拾取点击后右键"重命名/删除"之外的编辑命令（上下文菜单完整版 007）。
- **范围锁定**：调整命中策略/阈值/高亮风格须修订本规格并重新批准。

## 6. 约束

- **拾取实现路线（待定夺，见 §7 决策点）**：CPU 侧数学射线 + 各类型命中测试
  （mesh：BVH/逐三角形；线：胶囊距离；点云：像素半径近邻 + 空间索引）；候选反面：GPU 离线
  拾取通道（额外渲染 pass + 通道纹理读回——带宽/同步成本）与深度采样采样拾取（受深度限制、线类不可用）。
  推荐 CPU 路线（确定性、可单测、与 G1 非有限协调）。
- **高亮方式（推荐）**：绘制时以"选中标识 uniform"覆盖高亮色（点云/网格/线统一：选中即换色/加亮），
  零资源重传；候选：二次通道（额外 draw 成本）、嵌灯（无光照非目标）。
- 命中计算在 UI 线程（点击率低）；点云近邻需空间索引（`io`/`display` 侧构建，懒建+对象替换失效）。
- 坐标转换：屏幕↔NDC↔射线（`anchor_to_screen` 同族函数新增 `screen_to_ray`，core 数学，可单测）。
- 语义色与高亮色共用 004 色板；i18n 文案走 key 表（新键 2-3 个）；A9 守卫照旧。
