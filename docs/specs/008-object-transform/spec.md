## 1. 问题陈述

005 之后"选中"只是观察：选中对象只能聚焦/删除，无法改变其在场景中的位姿。机器人场景的布局调整
（点云对齐地图、frame 摆位）需要**直接操作**：拖拽 Gizmo 移动/旋转/缩放选中对象。本功能引入首个
**工具模式**（导航/变换）与 3D gizmo——兑现 004 工具条"互斥模式感按钮组/状态栏当前工具"与
005 §5"未来工具占位另立项"的预留。

**取代声明**：`005-picking-selection spec.md` §5 的"不做对象拖拽变换/旋转 Gizmo（路线图序号 008）"
由本功能取代（进入已实现）；005 修订行登记（批准时落位）。

## 2. 成功指标（可测试）

| # | 指标 | 判定 |
|---|---|---|
| M1 | 工具模式 | 工具栏互斥工具组（导航/变换）可切换；状态栏显示当前工具；变换工具激活时拖拽=变换（非环绕），导航工具时行为与 004 主路径一致 |
| M2 | Gizmo | 选中对象在变换工具下显示移动/旋转/缩放手柄（语义色，004 色板+002 轴色对表）；拖拽手柄产生对应变换 |
| M3 | 变换应用 | 拖拽变换实时生效（≤1 帧）；变换作用于对象整体（点云/网格/路径/frame/marker 逐类）；非有限/退化输入不 panic |
| M4 | 精确输入 | 属性面板/右键提供数值输入（位移 xyz/旋转/缩放）；步进、点击即键入随 007 DragValue 规范 |
| M5 | 回归 | 001–007 全量语义等价 + 路径守卫 + 五门禁 |

## 3. 用户故事

- **US1**：我选中网格 → 拖拽移动手柄 → 它在视口中平滑跟随；右侧属性同步显示新坐标。
- **US2**：我旋转 frame 的方向；X/Y/Z 轴色保持世界语义色（002 锁定）不变。
- **US3**：我右键选中的对象 → "变换→重置"回到初始位姿。
- **US4**：变换后我重新加载数据——回到文件的原始位姿（变换仅会话内，见非目标）。

| # | 验收 | 渠道 |

## 5. 非目标（本功能不做）

- 不做多选/群组变换（005 非目标延续）。
- 不做撤销/重做历史（另立项：命令历史/撤销栈）。
- 不做对象动画/关键帧（009 timeline 承载范围外）。
- 不做变换持久化：数据文件只读语义不变，变换为会话内状态。
- 不做 gizmo 定制（尺寸/颜色/手柄类型用默认集）。
- **范围锁定**：新增变换类型（轴对齐约束/吸附）、撤销栈、或变换参与场景持久化须修订本规格并重新批准。

## 6. 约束

- **工具模式（§7 D1）**：轻量工具态枚举 `Tool{Nav, Transform}`（app 层；复用 004 工具条互斥按钮组与
  状态栏"当前工具提示"）；005 拾取=导航工具内点击语义（点击=选中、拖拽=环绕），不受影响；变换工具下
  点击=选中开始变换。
- **Gizmo 实现路线（§7 D2）**：候选自研（core 数学：屏幕/主平面手柄 + 鼠标 delta→世界变换，纯函数可
  单测）或第三方 gizmo crate（需按技术可行性审核流程实证版本/许可/MSRV）；egui 0.32 无内建 3D gizmo。
- **变换数据归属（§7 D3）**：每对象变换（位置/旋转/缩放）建议入 core 数据模型（`SceneObject` 增
  位姿字段；仿射作用于渲染/拾取/包围盒）——渲染（004 通道）、命中（005）、未来持久化/序列/撤销均引用；
  本功能允许的 core 数据模型扩展面由 D3 裁定（不违背 004 层界——004 层界系 004 交付时的面，新功能可扩展）。
- **变换与渲染/拾取协同**：渲染按对象位姿（与 004 per-object 通道协同，D3 落实细节）；拾取命中需
  反变换（射线→对象局部空间/平面求交，core 纯函数可单测，005 数学同族）。
- **快捷键（§7 D4）**：候选 G=移动、S=缩放、R=旋转（与 007 键表 R=重命名冲突——重命名改 F2 或变换键
  另选）、T=切换工具；与 `007-interaction-polish spec.md` §6 键表联动修订。
- i18n：工具名/手柄提示/右键"变换→重置"键入 key 表；路径守卫（`001-point-cloud-viewport spec.md` A9）照旧。
