## 1. 问题陈述

固定场景已可观察，但机器人/仿真数据本质是**时间序**的：帧寻址、回放、步进是数据工具的基本特征。
本功能引入时间线面板（播放控制 + 当前帧指示 + 序列数据最小接口），兑现 004 §5"时间线 scrub
（路线图序号 009）"的预留；面板宿主依赖 006 的可停靠机制（本功能为 006 之后的首个新面板类型）。

**取代声明**：`004-ui-blueprint spec.md` §5 的"不做时间线 scrub（路线图序号 009）"由本功能取代
（进入已实现）；004 修订行登记（批准时落位）。

## 5. 非目标（本功能不做）

- 不做时间线编辑（增删帧/标注——另立项）。
- 不做视频/流式/实时订阅数据。
- 不做多时间线/嵌套片段。
- v1 不做帧插值/动画混合（按数据契约做切片切换或整帧替换）。
- **范围锁定**：引入时间轴编辑/动画插值/新序列数据格式须修订本规格并重新批准。

## 6. 约束

- **面板宿主时机（§7 D1）**：006 之后实现（面板注册表/多 surface/布局持久化先立）；无数据时为精简模式。
- **时序数据接口（§7 D2）**：core 层最小抽象（候选 a：`TimelineData`——帧时刻表 + 每帧对象数据引用/
  快照，回放=逐帧替换/重建；候选 b：仅 UI 骨架 + 接口定义，数据绑定后置；序列**数据格式**若属新
  格式则另立项（010-sequence-format），本功能只消费已有格式或接口）。数据绑定 v1 契约范围由 D2 裁。
- UI 复用：播放控制图标/键位经 007 键表（空格=播放/暂停 提案需 007 联动修订）；时间戳/帧率显示与
  004 状态栏相邻（时间线面板专属区）。
- i18n：新键（播放/暂停/步进/循环/占位引导）；路径守卫（`001-point-cloud-viewport spec.md` A9）照旧。
- 与 006 布局持久化：面板关闭/重开随注册表语义（006 A6）。
