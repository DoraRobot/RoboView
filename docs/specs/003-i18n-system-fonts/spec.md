## 1. 问题陈述

两个已被实际触发的缺陷：

1. **字形覆盖**：egui 默认字体链（拉丁/emoji/图标子集）不含 `→`（U+2192）等符号——display-types 的提示文案已因此出现豆腐块（已用 ASCII 临时规避）；将来中文等任何非拉丁文案将**系统性**遇到同类缺失（CJK 缺口是符号的百倍规模）。
2. **文案硬编码英文**：`texts.rs` 虽集中（i18n-ready 结构），但没有 locale 概念与切换机制——多语言是项目既定方向（§1.1、§6.5）。

本功能把"文案层 i18n 骨架"与"字体层系统字体"一次落地：**应用文案支持 en/zh-CN 两种语言（OS 语言自动检测 + 运行期切换），字体经系统字体加载（零打包体积），符号/CJK 缺口由系统字体族补齐**。

## 3. 用户故事

- **US1**：我把系统语言设为中文后启动 RoboView → 界面自动全中文。
- **US2**：我在运行中打开语言菜单切换到 English → 所有文案即时切换，无需重启。
- **US3**：我在无论哪个平台上输入/渲染含 `→` 与中文的界面文案 → 无豆腐块。
- **US4**：某条文案缺翻译 → 显示英文 + 日志警告，应用不崩。

## 5. 非目标（本功能不做）

- 不做第三种语言（ja/de……语言树骨架预留，但本期仅 en/zh-CN）；不做 RTL。
- 不打字库：不打包任何字体文件（纯系统字体加载；ADR 003 字体路径仅为未来备选，**本功能不落盘字体**）。
- 不做语言选择持久化（重启后按 OS 语言；会话内记忆）。
- 不做文本排版质量保证（断行/换行/宽度微调）、不保证系统字体缺失时的视觉完美（回退策略见 §6）。
- 不做日期/数字/单位本地化格式（后续独立功能）。
- 不做"翻译质量"治理（人工翻译由贡献者在 PR 中完成，本功能只建机制）。
- 不构建字体选择 UI（用户不选字体，只有语言选择）。
- 不修改 core：i18n/字体全部在 app 层（core 零文案零字体，既有不变式）。

## 6. 约束

- **字体方案（已定向）**：系统字体加载（`egui_system_fonts` 或等效 fontdb 系，**逐许可核验**：MIT/Apache 双许可优先，deny 白名单内，进 `[workspace.package]`…… 实现选型见 plan.md）；启动时扫描系统字库，构造 egui `FontDefinitions`：Proportional/Monospace 族回退链 = 「拉丁默认（egui 内建）→ 系统通用族（sans-serif 提供符号/箭头）→ 按 locale 语言字体族（zh: PingFang SC / Microsoft YaHei / Noto Sans CJK —— 平台候选清单）」；扫描失败/无系统字体 → 静默回退 egui 内建字体（记日志，不失败——M1 判定降级参考记录需注明）。
- **locale 机制**：`Locale { En, ZhCn }`；系统检测：`sys-locale`/等效（逐许可核验）→ 默认 En；运行期切换：设置菜单（File→Language 子菜单或 Settings 面板——实现细节 plan 定）；文案层：现有 `texts.rs` 改造为 key 化表（`enum TextKey` 或 locale 结构体 + 常量，**保留现有常量接口兼容**——决策点 D3）；core 不变式保持（无文案字符串）。
- **渲染契约**：字体仅影响 egui 文本（3D 场景无文本）；label/overlay 属 egui 绘制层不受影响。
- **A9/A12**：新文本不含数据路径；language 菜单文案进 texts。
- **性能**：字库扫描一次性（启动早阶段），缓存；不允许每帧扫描/加载。

## 7. 决策点（待人工确认；确认后随批准删除并落位正文）

- **D1 字体加载依赖**：`egui_system_fonts`（成熟、MIT；egui 生态专用）vs 自研 fontdb 加载器（可控但工作量大）。**建议 egui_system_fonts**；若其 API 与 egui 0.32 不匹配（版本对表 failure 时），fallback 到 fontdb 直接实现（plan 记录）。
- **D2 语言检测依赖**：`sys-locale`（极简、零依赖可选；返回语言标签）vs OS API 自绘。**建议 sys-locale**（逐许可核验）。
- **D3 texts 改造方式**：key 化表 + 保留现有常量名（防现有调用改动——已有 40+ 常量引用在 UI）vs 全量重构为 `t!(ctx, Key)` 宏/函数（更彻底但改动面大）。**建议**：`Locale` 参数化函数表 + 常量名保留为"当前 locale 的 getter"——具体形态 plan 定，spec 只锁"现有调用面尽量不动"。
- **D4 zh 翻译集范围**：本期翻译清单 = 现有 texts.rs 全部文案（约 45 条）+ 本功能新增（语言菜单）。以现有英文为准逐条中文。
