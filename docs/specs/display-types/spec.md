## 1. 问题陈述

首个功能验证了"单文件 → 单点云 → GPU 视口"链路，但场景模型是单显示槽位，无法同时呈现
机器人场景的多个元素。第二个功能把 RoboView 升级为"多对象场景"：同场景同时加载/显示
**网格、路径、坐标系、标记**与多个点云，通过**数据列表（固定侧栏）**管理显示对象，
并在 GPU 上使用**共享深度**正确绘制。

**取代声明**（与首功能契约的关系）：多对象语义下，"打开文件"由首功能 A7/US2 的
**单槽替换**（第二次打开替换第一次）显式修订为**追加**（新对象加入场景、列表按添加序展示）。
首功能 A7/US2 的失败路径（打开失败保留已有对象 + 可读错误）由本功能 A10 继承，语义不变。
首功能 spec.md 修订行与本 spec 修订行同步登记该取代关系（见本文件修订记录）。

## 3. 用户故事

- **US1**：我打开一个 OBJ 网格文件，它在视口中显示为实体网格；旋转视角时网格自遮挡与对象间遮挡正确（不穿帮、无闪烁）。
- **US2**：我打开一个路径文件，路径以折线显示；点云与路径叠加关系清晰。
- **US3**：我通过侧栏 UI 添加坐标系（frame，原点 XYZ 三轴 + 标签）与标记（文本标签/箭头）。
- **US4**：左侧列表显示全部对象（名称/类型/显隐）；点击行选中、切换显隐、删除；删除后对象消失且无 GPU 资源累积。
- **US5**：打开损坏/不支持格式 → 可读错误、不崩溃、已有对象保留（继承首功能失败路径语义）。
- **US6**：连续打开多个文件：对象逐个加入列表（追加），视角不因新对象而跳变（Fit 按钮手动取景到全体）。

## 4. 验收标准（渠道：CI=自动，UT=单测，MAN=手工）

**复合验收场景 C（统一定义）**：1M 点云 + ≥100k 面网格（OBJ）+ ≥1 frame + ≥1 marker，
≥5 显示实例且覆盖 ≥3 类；样本由验收方提供或使用公开标准样本（存私有区，不进入仓库，同首功能 A12 模式）。
**遮挡固定协议 P**：探针场景 = 平板网格 + 1M 点云前后穿插（点云按表面前/背面分两色组）；
固定相机路径 = 自动环绕、俯仰 −20°、连续 ≥300 帧；抽样角度集 = {0°, 90°, 180°, 270°}。
判据：① 深度次序——各抽样角度捕获帧中"背面组"像素占比 ≤ 0.1%；
② 无闪烁——环绕全程相邻帧组色翻转像素占比 < 0.5%，且同一角度两次独立捕获像素一致率 ≥ 99.9%；
③ 穿行观感（相机贴近/穿过网格表面时的体感）列为参考记录，不计入通过判定。
凡引用 P 的 A 行按同一协议执行。

| # | 验收 | 渠道 |
|---|---|---|

## 5. 非目标（本功能明确不做）

- 拾取（点击选中/高亮统计）、对象拖拽变换、任何针对单类型的属性/样式编辑面板（"添加对话框内参数"与"场景内编辑面板"分离：前者属本功能，后者不做；frame 长度在 Add 对话框内可设，非场景内编辑）。
- 撤销/重做（含删除恢复）。
- 列表多选、批量显隐/删除、拖拽重排（顺序固定为添加序）。
- frame 朝向/位姿编辑（仅世界系对齐三轴）、坐标轴样式 UI。
- 场景/会话持久化（重启即空场景）。
- 不新增打开入口（仅原生对话框；拖放、命令行打开不做——复述首功能非目标）。
- 渲染模式切换 UI（网格实体/线框）、路径平滑/插值开关类 UI（渲染方式由实现定，无用户选项）。
- TF 树/帧传递、多帧序列播放、动画。
- 网格：材质/贴图（`usemtl/mtllib` 忽略）、多材质、非三角面（多边形整文件拒绝）、**vn 校验但不参与着色**（着色语义见 §6）。
- 路径：插值（分段直线）、宽度/虚线 UI、箭头流场；**无地理投影/坐标变换**（经纬度→米制不做，文件坐标按数值原样显示）。
- marker：精灵/图标贴图、批量 CSV 标签导入、标记清单导入导出。
- 数据源闭环（无第二通道、无网络）。
- 2D 视图；egui_dock 停靠布局（本功能用固定侧栏；dock 推迟到出现 ≥2 个可停靠面板的功能，届时版本重新对表 egui）。

## 6. 约束

- 技术栈沿用 ADR 006；核心**无 GUI 依赖**（§2.4.1）；`egui`/`rfd`/侧栏组件只进 app。
- **共享深度路线（已裁定）**：宿主以 `depth_buffer=24` 开启共享深度（每帧 Clear(1.0)、随 surface 尺寸自动重建）；
  全部场景管线（点云/网格/线）按同一深度格式（Depth24Plus）构建——管线与 pass 的深度格式与采样数必须严格一致；
  本期保持 multisampling=1（如开启 MSAA，管线按采样数重建）。首功能契约（单帧单提交、不建 encoder/pass/submit、
  设备由宿主注入）**字面不变**；渲染参数化（深度格式/采样数）为唯一契约扩展，现有点云管线重建为已知回归面（A11）。
- **网格着色语义（已裁定）**：恒定面颜色 + 无光照（或头灯等效）；双面渲染（不剔除）；
  面法线由 CPU 按面计算、顶点复制（每面 3 顶点，无索引缓冲）——不用 WGSL 屏幕导数；
  `vn` 接受并校验越界、不参与着色。
- **共面/z-fighting 政策（已裁定）**：mesh 管线配深度偏置（把网格推远），使贴面点云/线稳定可见；
  线类图元（路径、坐标轴）不受 polygon offset 影响，采用严格 Less（与网格偏置配合）；
  文本标签为**视口覆盖层**（egui painter 绘制、始终置顶），不参与 M3 深度判定。
- **对象稳定 id（WHAT 级语义）**：每个显示对象持有单调递增的稳定 id；删除/显隐以 id 为句柄；
  列表按添加序（id 序）展示。
- **相机取景（已裁定）**：首次（空场景）添加成功后按全体对象并集取景；后续添加不改动相机（用户保持当前视角）；
  视口提供 Fit 按钮（单 UI 元素：取景到全体对象并集）；删除全部对象后回到空视口提示（沿用首功能 A1 口径）。
- 显示对象生命周期：显隐不释放资源（仅跳过绘制）；删除 = 移除条目 → drop → 资源经宿主图形 API 延迟销毁语义
  释放（A6 台账判据）；无累积泄漏。
- 解析防护：OBJ/CSV 沿用计数预校验（u128 上限防 OOM）；OBJ/CSV 无 magic → "扩展名 + 首行冒烟校验"
  （明确弱化后的双校验口径，A10 错误路径语义与此对应）；NaN/Inf 顶点与首功能 G1 政策对齐（保留 + 渲染侧裁剪）；
  每格式族 `thiserror` 错误 + 公共分发；文案统一 `texts.rs`（§2.5、§6.5）。
- 新增依赖（若有）：许可兼容（deny 白名单）、提交信息写明用途（§2.8.1）；独立依赖提交（§2.8.4）。

## 7. 类型与数据来源（本期锁定；范围调整须修订本规格并重新批准）

| # | 类型 | 数据来源 | 关键裁定与拒绝规则 |
|---|---|---|---|
| F1 | 网格 | **OBJ**（ASCII）| 解析：`v`/`vn`/`f`；`f` 仅 3 顶点/行（更多整文件拒绝并说明"仅三角形面"）；负索引显式拒绝（可读错误）；`f v/vt`、`f v//vn` 与裸 `f v` 可混用——`vt` 忽略、`vn` 校验越界不参与着色；`o/g/s/mtllib/usemtl` 等未知行整行忽略；CRLF/UTF-8 转义按字节 token 化；整文件单显示对象（不按 `o/g` 分组）；`v` 无 `f` → 整文件按散点；计数上限预校验后分配 |
| F2 | 路径 | **CSV/XYZ**（每行 `x y z`）| 分隔符 `[,\t ]+`、恰 3 token 否则报行号；整行 `#` 注释（行尾注释不支持）；首行含非数值 → 标题行；空行跳过；点 < 2 → 可读错误；整文件一条开放折线（无多段/闭合标记）；无地理投影/坐标变换；坐标非有限值按 G1 对齐保留 |
| F3 | 坐标系 | **UI 添加**（"Add frame"）| 原点（xyz 可输入）+ 长度（可输入）；朝向固定世界系；三轴 X 红/Y 绿/Z 蓝 + 轴标签（X/Y/Z 英文）；移除按钮；无文件形态（TF 树/位姿清单后续功能） |
| F4 | 标记 | **UI 添加** | 文本标签：锚点（xyz 可输入）+ 文本（可编辑、英文默认）——视口覆盖层；箭头：起点/终点（xyz 可输入）+ 箭头帽；各一个（可多个，同类型多实例）；移除按钮；保存/导入清单不在本期 |
