## 1. 问题陈述

蓝图/拾取/停靠完成后，交互密度与成熟 3D 工具仍有差距：无全局快捷键（只有 005 的 F/Delete）、
右键菜单不完整（004 只做树上三项）、数值输入控件不统一（步进/单位/右键输入缺失）、无图标集
（工具栏裸文字）、错误/警告仍以孤岛窗口+状态栏并存（003 机制）、视口 HUD 信息不全。
本功能统一补齐**交互密度的最后一档**。

**取代声明**：`003-i18n-system-fonts spec.md` §6.4 的"错误窗口每帧按当前 locale 组装"机制与
`003-i18n-system-fonts spec.md` A4"已打开的错误窗口随切换更新"子判据由本功能消息中心取代：孤岛错误窗
撤销（`ErrorEvent` 显示路径迁移），**已存消息随当前 locale 重渲染**（继承 003 每帧组装语义，
003 A4/M2 相关 MAN 判据按语义等价重定向）；003 spec 修订行随本功能批准登记。

## 3. 用户故事

- **US1**：我按 F 聚焦、按 Delete 删除、按 R 重命名（树内），按 1/2/3 切换视图预设视角——工具感拉满。
- **US2**：我右键视口 → 弹出"添加/重置视角/视图选项"；右键树行 → 重命名/显隐/删除/复制。
- **US3**：错误出现在底部消息中心（橙色警告/红错误、时间戳），可单条清除与全清。
- **US4**：工具栏/树行全部图标化（含 tooltip），无豆腐块。

## 5. 非目标（本功能不做）

- 不做自绘主题/皮肤系统（004 色板为界）；不做动态布局动画（工具感不靠特效）。
- 不做命令面板（Cmd+K 式）与插件化 UI 扩展（另立项）。
- 不做图标全面重绘（用图标源既有字形选择，见 §6；不做专有图标工程）。
- 不做多语言文案的词面润色（翻译质量治理另立项）。
- **范围锁定**：新增全局快捷键/新增右键命令类别/更换图标源须修订本规格并重新批准。

## 6. 约束

- **快捷键集（基表）**：F=聚焦（005，迁入本表）；Delete=删除（005，迁入本表）；R=重命名（树内/选中对象）；
  1/2/3=前/顶/侧视图；Ctrl+R=重置视角；Ctrl+O=打开；Ctrl+S=立即落盘（与 006 退出即存并存）；
  ?（shift+/）=打开快捷键表。**双路径规则**：裸键（F/Delete/R/1/2/3/?）一律 egui 层 +
  `wants_keyboard_input()` 焦点门控（无文本焦点才激活），**不得**注册为 macOS 菜单 key equivalent
  （会拦截文本输入）；Cmd/Ctrl+组合键在 macOS 入原生菜单（系统层触发、不受焦点影响），Win/Linux 由
  egui 层处理——平台映射（macOS Cmd+O/S/R vs Win/Linux Ctrl+O/S/R），AppAction 语义共享一致。
  冲突检测：表内唯一性 UT + 与 egui 内置保留键位集合比对。
- **右键菜单表**：树行=重命名/显隐/删除/复制；视口=**重命名/删除（选中对象，自 005 移交）**/重置视角/
  添加▾/视图选项；属性=重置默认值/复制属性名/放大控件帮助。
- **图标源（§7 D1 定案）**：`egui-phosphor 0.10.0`（配对 egui ^0.32 已核验、MIT OR Apache-2.0；
  未声明 rust-version——准入前一次 1.85 编译验证；字形过 `003-i18n-system-fonts spec.md` A2 探测纪律）；
  `egui_phosphor_icons`（0.5.0→egui ^0.36，无配对 egui 0.32 的版本）不采用；内建 `emoji-icon-font`
  子集降级为回退；**禁止引入自制字体**。
- **消息中心**：底部条升级为可展开消息列表（分级色/秒级时间戳/清空=单条+全部/年轮滚动）；时间戳口径：
  `ErrorEvent` 结构无时间戳字段——消息入中心时打点（取入中心时刻，事件构造处传入，plan 落位）；
  003 错误机制撤销并登记取代（`ErrorEvent` 显示路径迁移：`main.rs` error_window 撤除，事件结构保留、
  "模板可译/reason 不译"分层保留；004 轻量消息条随迁——004 §6 预登记的取代关系）。
- **HUD**：方位指示器（004 静态显示）点击对齐——点 X/Y/Z → 视角对齐正/负轴方向（与 1/2/3 预设并列；
  命中判定=指示器 2D 区域），交互归本功能。
- i18n：所有新菜单/提示/消息键入 key 表（约 20 键；文案首次出现处给英文规范形，防 key 表以中文为源）；
  路径守卫（`001-point-cloud-viewport spec.md` A9）照旧——守卫域=源码中 `.ply/.pcd/.obj/.csv/.xyz`
  数据路径字面量；图标资产经 `include_bytes!` 嵌入（带扩展名属正常，不与守卫冲突）。
