# interaction-polish — 规格

状态：Draft（草案）

日期：2026-09-02

相关：ADR 004、ADR 006；`docs/specs/003-i18n-system-fonts/`、`docs/specs/004-ui-blueprint/`、`docs/specs/005-picking-selection/`、`docs/specs/006-dock-layout/`（本功能为以上全部之上的体验收官）

> 跨 workspace 引用全限定；裸编号仅本 workspace 有效。

## 1. 问题陈述

蓝图/拾取/停靠完成后，交互密度与成熟 3D 工具仍有差距：无全局快捷键（只有 005 的 F/Delete）、
右键菜单不完整（004 只做树上三项）、数值输入控件不统一（步进/单位/右键输入缺失）、无图标集
（工具栏裸文字）、错误/警告仍以孤岛窗口+状态栏并存（003 机制）、视口 HUD 信息不全。
本功能统一补齐**交互密度的最后一档**。

## 3. 用户故事

- **US1**：我按 F 聚焦、按 Delete 删除、按 R 重命名（树内），按 1/2/3 切换视图预设视角——工具感拉满。
- **US2**：我右键视口 → 弹出"添加/重置视角/视图选项"；右键树行 → 重命名/显隐/删除/复制。
- **US3**：错误出现在底部消息中心（橙色警告/红错误、时间戳），可单条清除与全清。
- **US4**：工具栏/树行全部图标化（含 tooltip），无豆腐块。

## 4. 验收标准（渠道：CI=自动，UT=单测，MAN=手工）

| # | 验收 | 渠道 |
|---|---|---|
| A1 | 快捷键表逐项映射（≥10 项，含 F/Delete/R/1/2/3/空格等）；冲突检测 UT（表内唯一性） | UT+MAN |
| A2 | 三处右键菜单覆盖（树/视口/属性）每处 ≥3 命令可用（含各自语义） | MAN |
| A3 | 全应用数值 DragValue 化（抽样 5 处输入组件 + 右键输入行为） | MAN |
| A4 | 图标集嵌入且探测串无 .notdef（003 A2 复用）；icon 均为语义可辨 | UT+MAN |
| A5 | 错误/警告消息中心工作时间戳/分级/可清空；孤岛窗在 007 后不存在 | MAN |
| A6 | 视口角标 HUD：工具/相机姿态可见；悬停显示快捷键角标 | MAN |
| A7 | 回归：001–006 + A9 守卫 + 五门禁/三平台/msrv | CI+MAN |

## 5. 非目标（本功能不做）

- 不做自绘主题/皮肤系统（004 色板为界）；不做动态布局动画（工具感不靠特效）。
- 不做命令面板（Cmd+K 式）与插件化 UI 扩展（另立项）。
- 不做图标全面重绘（用图标源既有字形选择，见 §6；不做专有图标工程）。
- 不做多语言文案的词面润色（翻译质量治理另立项）。
- **范围锁定**：新增全局快捷键/新增右键命令类别/更换图标源须修订本规格并重新批准。

## 6. 约束

- **快捷键集（建议基表）**：空格=切换拾取模式；F=聚焦（005）；Delete=删除（005）；R=重命名；
  1/2/3=前/顶/侧视图；Ctrl+R=重置视角；Ctrl+O=打开；Ctrl+S=布局保存（006）；?(shift+/)打开快捷键表。
  冲突检测（新键与 egui 内置/文本输入焦点错开——egui 无焦点输入时才激活）。
- **右键菜单表**：树行=重命名/显隐/删除/复制；视口=重置视角/添加▾/视图选项；属性=重置默认值/
  复制属性名/放大控件帮助。
- **图标源（§7 D1）**：egui 内建 `emoji-icon-font` 可用字形优先；候选 `egui_phosphor_icons`
  （0.5.0，需版本对表 egui 0.32.3——若不对表则维持内建子集，另立项图标）；**禁止引入自制字体**。
- **消息中心**：底部条升级为可展开消息列表（分级色/时间戳/年轮滚动）；003 错误机制撤销并登记
  取代（ErrorEvent 显示路径迁移）。
- i18n：所有新菜单/提示/消息键入 key 表（约 20 键）；A9 守卫照旧（图标/路径不带点扩展名）。
