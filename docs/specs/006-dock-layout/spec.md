# dock-layout — 规格

状态：Draft（草案）

日期：2026-09-02

相关：ADR 004、ADR 006；`docs/specs/002-display-types/`、`docs/specs/003-i18n-system-fonts/`、`docs/specs/004-ui-blueprint/`（本功能前置：四区已固定）

> 跨 workspace 引用全限定；裸编号仅本 workspace 有效。

## 1. 问题陈述

004 之后面板数 ≥4（对象树/视口/属性/状态栏+消息条），固定分区开始限制工作流：
无法重组布局（想要"属性在左"或"大视口"）、无法并排双视图（预留）、布局随会话丢失。
本功能引入**可停靠面板布局系统**（06x 独立功能点）：面板可拖拽停靠/浮动/调宽，布局可保存/
加载/重置预设。

**取代声明**：002-display-types §5 与 003-i18n §5 的"不做布局持久化"非目标由本功能取代；
两者修订行登记。004 的"位置固定"限制解除（默认布局仍与 004 一致）。

## 2. 成功指标（可测试）

| # | 指标 | 判定 |
|---|---|---|
| M1 | 可停靠 | 全部面板（对象树/视口/属性/消息/预留时间线）可停靠至四个边缘或浮动；拖拽热区可用 |
| M2 | 调宽 | 侧面板可调宽（min/max 界）；视口自适应 |
| M3 | 布局持久化 | 布局保存 → 重启/重载后恢复（≤1 帧 布局加载完成）；修改后显式保存或自动保存策略见 §6 |
| M4 | 预设 | ≥2 预设（默认=004 布局 / 分析=窄树宽视口）；一键重置到默认 |
| M5 | 回归 | 004/005 全量（语义等价）+ A9 守卫 + 五门禁 |

## 3. 用户故事

- **US1**：我拖动属性面板到左侧，布局变为"属性｜视口｜树"；退出重启仍保持。
- **US2**：我点"布局→重置默认"回到 004 骨架；"布局→分析"预设给大视口。
- **US3**：我把"消息"面板浮动成窗口并关闭主窗口重开——随布局恢复。

## 4. 验收标准（渠道：CI=自动，UT=单测，MAN=手工）

| # | 验收 | 渠道 |
|---|---|---|
| A1 | 每个面板 dir 上有停靠热区；拖动至中/边缘成功（≥1 种停靠数变化）| MAN |
| A2 | 拖拽过程中无面板闪烁/错位；完成态一致（完成即有"松手后布局稳定"）| MAN |
| A3 | 调整宽度 min≤w≤max；视口区域尺寸跟随 | MAN |
| A4 | 保存布局 → 重启 → 恢复一致性（记录布局哈希比对或目视三点抽样）| MAN |
| A5 | ≥2 预设可切换；重置恢复默认 | MAN |
| A6 | 浮动面板关闭 → 布局记录中该面板状态正确（重开随布局恢复）| MAN |
| A7 | 布局文件损坏 → 回退默认 + 提示（不崩溃）| UT+MAN |
| A8 | 回归：001–005 + A9 守卫 + 五门禁/三平台/msrv | CI+MAN |

## 5. 非目标（本功能不做）

- 不做多视口（多 3D 视图并排）；不做布局导出/导入为文件共享；不做差异 diff/布局合并。
- 不做面板内"标签页组"的复杂级联（同一面板类型多实例——多视口预留机制，本期仅单实例）。
- 不做拖放对象到面板（数据视图语义，另立项）。
- 不做布局崩溃恢复的多级快照（仅 A7 单级回退）。
- **范围锁定**：引入新面板类型/多实例须修订本规格并重新批准。

## 6. 约束

- **依赖（待定夺，§7 D1）**：`egui_dock 0.17.0`（已核验：egui ^0.32 配对、MIT、rust-version 1.85、
  依赖 duplicate/paste 全宽松；本地无缓存需联网拉取——受限时用私有代理规则）；落 `crates/roboview`。
- **持久化**（§7 D2）：布局序列化存储于用户配置目录（`dirs`/平台约定路径或 eframe storage——
  推荐 eframe 自带 storage（`App::save`/`persistence` 自带 egui 序列化），零新持久化依赖；
  存储实现方案以 plan 定；配置文件属 app 数据，**不进入仓库**（A9 无关）。
- 默认布局 = 004 骨架；预设表（默认/分析）在 `theme.rs`-式默认集。
- 面板 id 稳定（布局恢复依赖）；i18n：重置/预设/保存菜单键入 key 表；A9 守卫照旧。
- 与 003 共存：语言切换与布局恢复互不干扰（面板文字随 locale，布局几何不随）。
