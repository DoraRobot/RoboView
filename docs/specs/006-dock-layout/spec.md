## 1. 问题陈述

004 之后面板数 ≥4（对象树/视口/属性/状态栏+消息条），固定分区开始限制工作流：
无法重组布局（想要"属性在左"或"大视口"）、无法并排双视图（预留）、布局随会话丢失。
本功能引入**可停靠面板布局系统**：面板可拖拽停靠/浮动/调宽，布局可保存/加载/重置预设。

**取代声明**：`001-point-cloud-viewport spec.md §5` 的"不做 UI 面板停靠（egui_dock）、布局持久化"与
`002-display-types spec.md §5` 的"egui_dock 停靠布局（推迟到出现 ≥2 个可停靠面板的功能）"由本功能取代；
**不取代** `002-display-types spec.md §5` 的"场景/会话持久化"（本功能只持久化布局，场景内容仍不持久化）
与 `003-i18n-system-fonts spec.md §5` 的"语言选择持久化"（互不相关）。001 与 002 修订行登记
（002 的"届时版本重新对表 egui"由本功能 D1 的 0.17.0/egui ^0.32 核验兑现）。004 的"位置固定"
限制解除（默认布局仍与 004 一致）。

## 3. 用户故事

- **US1**：我拖动属性面板到左侧，布局变为"属性｜视口｜树"；退出重启仍保持。
- **US2**：我点"布局→重置默认"回到 004 骨架；"布局→分析"预设给大视口。
- **US3**：我把"消息"面板浮动成窗口并关闭主窗口重开——随布局恢复。

| # | 验收 | 渠道 |
|---|---|---|

| A4 | 保存布局 → 重启 → 恢复一致性（布局哈希比对）| UT+MAN |

| A6 | 浮动面板经面板级"浮动"入口（`DockState::add_window` 多 surface API）开；关闭 → 注册表记录状态；重开=回默认坞位 | MAN |

## 5. 非目标（本功能不做）

- 不做多视口（多 3D 视图并排）；不做布局导出/导入为文件共享；不做差异 diff/布局合并。
- 不做面板内"标签页组"的复杂级联（同一面板类型多实例——多视口预留机制，本期仅单实例）。
- 不做"拖出即浮"的拖拽自动浮动：浮动经面板级入口（`DockState::add_window`）；拖出即浮为实现期 spike，若验证不可行则以浮入/浮出按钮满足 M1。
- 不做拖放对象到面板（数据视图语义，另立项）。
- 不做布局崩溃恢复的多级快照（仅 A7 单级回退）。
- **范围锁定**：引入新面板类型/多实例须修订本规格并重新批准。

## 6. 约束

- **依赖（定案，§7 D1）**：`egui_dock 0.17.0`（已核验：egui ^0.32 配对、MIT、rust-version 1.85、
  依赖 duplicate/paste 全宽松；serde 可选且**非默认——必须显式开启 `serde` feature**（`features = ["serde"]`，
  DockState 序列化前提；本地无缓存，需联网拉取）；依赖方向已由 ADR 006 收敛（本决策仅为版本/许可
  核验确认）；落 `crates/roboview`。
- **持久化（定案，§7 D2）**：经 eframe storage（`App::save`/`persistence`）——`crates/roboview` 现有
  eframe **未开 `persistence` feature**，需开启（新增传递依赖 ron/home，均 MIT OR Apache-2.0，在 deny
  allowlist 内；非"零新依赖"但最小）；egui persistence 会顺带持久化 egui Memory（窗口几何/面板宽度），
  plan 说明取舍；布局文件属 app 数据，**不进入仓库**（与路径守卫无关，守卫域=源码路径字面量）。
- 默认布局 = 004 骨架；预设表（默认/分析/简洁——简洁=视口优先、侧面板收起/悬浮，对应"视图最大化"习惯）
  在 `theme.rs`-式默认集（以 004 批准布局为准，004 骨架变动时同步维护）。
- **面板注册表**（A6 语义）：app 层维护 PanelId 全集（树/视口/属性/状态栏；消息面板若独立则纳入）+
  开/关位 + 关闭前位置快照（surface/坞位）；egui_dock 的"关闭"=移除 tab、不记忆原位置——关闭/重开
  统一"回默认坞位"，注册表保证状态正确、不崩溃；面板 id 稳定（布局恢复依赖）；i18n：重置/预设/保存
  菜单键入 key 表；路径守卫（`001-point-cloud-viewport spec.md` A9）照旧。
- 与 003 共存：语言切换与布局恢复互不干扰（面板文字随 locale，布局几何不随）。
